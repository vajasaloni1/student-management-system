# Student Management System

Student Management System is a web-based application used to manage student records and academic information efficiently.

## Features
- Student Registration
- Add, Update & Delete Student Records
- Search Student Details
- Manage Courses & Information

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Purpose
This project helps in maintaining student data digitally and reduces manual record management work.
